**每一次录音的长度**

按前几次录音的语速（每分钟大约一百九十五个字，连停顿和即兴的话算在内），一次控制在二十三分钟左右：讲稿正文大约四千三百字。章太长就分上下（或上中下），断在意思转折的地方。每一次的开头，先把这一次要讲的原文连起来通读一遍，再一句一句讲。

**命名规则**

- 讲稿：`两位章号-第X章.md`，比如 `04-第四章.md`。一章分几次讲时，加 `-上` `-下`（或 `-1` `-2` `-3`），比如 `05-第五章-上.md`。
- 示意图：放在 `图/`，文件名用"章号-序号-图名"，比如 `02-3-奥古斯丁的图.png`，一看就知道属于哪一章。
- 示意图都是 16:9，可以直接放进视频画面。改图或加图：改 `video/tools/lecture_figs.mjs`，然后运行 `node tools/lecture_figs.mjs`（在 `video/` 目录下）。
